## 📖 Over het project

**Het mysterie van de avondschool** is een gameproject dat is ontwikkeld voor de opdracht *Design Your Game*. De game draait om een mysterie op een avondschool en combineert gameplay, sfeer en creativiteit in één ervaring.

In deze repository vind je de broncode en projectbestanden die bij de game horen.

## ✨ Features

- 🎮 Een game met een mysterieus avondschoolthema.
- 🕵️ Een project waarin ontdekking en mysterie centraal staan.
- 💻 Broncode en projectbestanden voor verdere ontwikkeling.
- 🧩 Ontwikkeld in het kader van de opdracht *Design Your Game*.

## 🛠️ Technologieën

- **Programmeertaal:** C#
- **Projecttype:** .NET / gameproject
- **Versiebeheer:** Git en GitHub

*Controleer de projectinstellingen voor de exacte framework- en .NET-versies.*

## 🚀 Installatie

Wil je het project lokaal uitvoeren? Volg dan deze stappen.

### 1. Repository clonen

```bash
git clone https://github.com/BjornPraamsma/Het-mysterie-van-de-avondschool.git
```

### 2. Project openen

1. Open de gekloonde repository.
2. Open de map `Game`.
3. Open het solution-bestand (`.sln`) of projectbestand (`.csproj`) in Visual Studio.
4. Herstel eventuele ontbrekende afhankelijkheden.

### 3. Game starten

Start het project vanuit Visual Studio met **F5** of via de knop *Start*.

De exacte startprocedure is afhankelijk van de projectconfiguratie.
